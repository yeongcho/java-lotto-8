# java-lotto-precourse

## 프로젝트 개요

- 로또 게임 시뮬레이터
  - 사용자로부터 구입 금액과 당첨 번호를 입력받아 랜덤으로 발행된 로또와의 일치 여부를 판별하고, 등수별 당첨 통계와 수익률을 계산해 출력하는 프로그램

---

## 기능 구현 목록

### 1. 입력 기능

- 구입 금액을 입력받는다.
  - 입력값이 1000원 단위인지 검증한다.
  - 숫자가 아닌 값을 입력하면 `[ERROR] 입력은 숫자만 가능합니다.` 메시지를 출력하고 재입력을 요구한다.

- 당첨 번호를 입력받는다.
  - 쉼표(`,`)로 구분된 여섯 개의 숫자를 입력받는다.
  - 1~45 범위를 벗어나거나 중복된 숫자가 있으면 예외 발생.

- 보너스 번호를 입력받는다.
  - 1~45 범위 내의 숫자만 입력 가능.
  - 당첨 번호와 중복되면 예외 발생.

### 2. 로또 발행 기능

- 구입 금액을 통해 발행할 로또 개수를 계산한다. (`금액 / 1000`)
- 1~45 사이의 숫자 중 6개를 중복 없이 랜덤으로 뽑아 로또를 생성한다.
- 각 로또 번호는 오름차순으로 정렬하여 출력한다.

### 3. 당첨 비교 기능

- 각 로또별로 당첨 번호와 일치하는 개수를 계산한다.
- 보너스 번호 일치 여부를 확인한다.
- 일치 개수 및 보너스 번호 여부를 기준으로 등수를 결정한다.
  - 6개 일치 → 1등 (2,000,000,000원)
  - 5개 + 보너스 일치 → 2등 (30,000,000원)
  - 5개 일치 → 3등 (1,500,000원)
  - 4개 일치 → 4등 (50,000원)
  - 3개 일치 → 5등 (5,000원)

### 4. 당첨 통계 및 수익률 계산 기능

- 각 등수별 당첨 횟수를 집계한다.
- `(총 당첨 금액 / 구입 금액) * 100`으로 수익률을 계산한다.
- 소수점 둘째 자리에서 반올림하여 출력한다.
- 아래 형식으로 출력한다.  
    - 3개 일치 (5,000원) - 1개
    - 4개 일치 (50,000원) - 0개
    - 5개 일치 (1,500,000원) - 0개
    - 5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
    - 6개 일치 (2,000,000,000원) - 0개
    - 총 수익률은 62.5%입니다.

### 5. 예외 처리 기능

- 모든 입력 검증은 `LottoValidator` 유틸 클래스를 통해 수행한다.
- 예외 발생 시 `[ERROR]`로 시작하는 메시지를 출력하고, 재입력을 요구한다.
- 예외 조건
  - 구입 금액이 1000원 단위가 아닐 때
  - 숫자가 아닌 값이 입력되었을 때
  - 로또 번호가 1~45 범위를 벗어날 때
  - 중복된 번호가 있을 때
  - 번호의 개수가 6개가 아닐 때
  - 보너스 번호가 당첨 번호와 중복될 때

### 6. 테스트 코드

- 구입 금액 검증 테스트 (1000원 단위 확인)
- 로또 번호 범위 및 중복 테스트
- Rank Enum 테스트 (매칭 로직 검증)
- 당첨 결과 계산 테스트 (단독/공동 우승)
- 수익률 계산 테스트 (반올림 확인)
- 잘못된 숫자 형식 입력 테스트 (`NumberFormatException` 처리 확인)

### 7. 실행 흐름

1. 구입 금액 입력
2. 로또 생성 및 출력
3. 당첨 번호 입력
4. 보너스 번호 입력
5. 당첨 결과 계산
6. 수익률 출력
