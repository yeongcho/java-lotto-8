# java-lotto-precourse
## 기능 구현 목록

### 1. 입력 기능

- 구입 금액을 입력받는다.
    - `"구입금액을 입력해 주세요."` 출력
    - `Console.readLine()`으로 입력
    - 1000원 단위인지 검증 (나누어떨어지지 않으면 예외 발생)

- 당첨 번호를 입력받는다.
    - `"당첨 번호를 입력해 주세요."` 출력
    - 쉼표(`,`) 기준으로 분리
    - 각 번호가 1~45 범위 내인지, 중복이 없는지 검증

- 보너스 번호를 입력받는다.
    - `"보너스 번호를 입력해 주세요."` 출력
    - 1~45 범위 검증
    - 당첨 번호와 중복되지 않아야 함

### 2. 로또 발행 기능

- 구입 금액을 통해 로또 수량을 계산한다. (`금액 / 1000`)
- `Randoms.pickUniqueNumbersInRange(1, 45, 6)`을 사용하여 로또 번호 생성
- 각 번호를 오름차순 정렬하여 `Lotto` 객체로 생성
- 생성된 모든 로또를 리스트로 관리
- `"N개를 구매했습니다."` 및 각 로또 번호를 출력

### 3. 당첨 비교 기능

- 각 로또별로 당첨 번호와 일치하는 개수를 계산한다.
- 보너스 번호 일치 여부를 확인한다.
- 일치 개수와 보너스 여부를 기준으로 등수를 결정한다.
    - 6개 일치 → 1등 (2,000,000,000원)
    - 5개 + 보너스 → 2등 (30,000,000원)
    - 5개 일치 → 3등 (1,500,000원)
    - 4개 일치 → 4등 (50,000원)
    - 3개 일치 → 5등 (5,000원)

### 4. 당첨 통계 및 수익률 계산 기능

- 각 등수별 당첨 횟수를 집계한다.
- `(총 당첨 금액 / 구입 금액) * 100`으로 수익률을 계산한다.
- 소수점 둘째 자리에서 반올림한다.
- 아래 형식으로 출력한다.  
    - 3개 일치 (5,000원) - 1개
    - 4개 일치 (50,000원) - 0개
    - 5개 일치 (1,500,000원) - 0개
    - 5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
    - 6개 일치 (2,000,000,000원) - 0개
    - 총 수익률은 62.5%입니다.

### 5. 예외 처리 기능

- `[ERROR]`로 시작하는 메시지를 출력한다.
- `IllegalArgumentException`을 발생시켜 잘못된 입력에 대한 재입력을 요구한다.
- 예외 조건
- 구입 금액이 1000원 단위가 아닐 때
- 로또 번호가 1~45 범위를 벗어날 때
- 중복된 번호가 있을 때
- 번호의 개수가 6개가 아닐 때

### 6. 테스트 코드

- 구입 금액 검증 테스트 (1000원 단위 확인)
- 로또 번호 범위 및 중복 테스트
- Rank Enum 테스트 (매칭 로직 검증)
- 당첨 결과 계산 테스트 (단독/공동 우승)
- 수익률 계산 테스트 (반올림 확인)

### 7. 실행 흐름

1. 구입 금액 입력
2. 로또 생성 및 출력
3. 당첨 번호 입력
4. 보너스 번호 입력
5. 당첨 결과 계산
6. 수익률 출력
